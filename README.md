## 欢迎来到我的工具小窝

这里是 **NachoNeko**，欢迎来拾光坐坐喵。

你有没有过这样的时刻：只是想找一款顺手的软件，结果打开了好多网页，看完推荐又看对比，工具还没选好，半个下午已经悄悄溜走了。

所以，我把值得认识的好工具整理在了一起，做成了 **拾光 Lumitime**。

它是一份用心挑选的软件清单，也是一扇通往灵感的小窗。希望你每次路过，都能带走一点有用的发现，而不是更多选择困难。

## 好工具，分门别类放好啦

从认真工作到安心摸鱼，总有一个角落适合现在的你：

- **效率办公**：整理笔记、安排计划，让事情有条不紊。
- **设计创意**：从一闪而过的灵感，到真正看得见的作品。
- **AI 工具**：寻找写作、研究与编程的得力搭子。
- **开发工具**：照顾代码，也照顾认真写代码的你。
- **影音娱乐**：给忙碌按下暂停键，让喜欢的声音陪一会儿。
- **系统工具**：打理数字生活里的小细节，让日常更顺手。

不知道从哪里开始？先逛逛精选集吧，就当是我用爪爪替你圈出的几个小推荐。

## 也想让寻找本身，好看一点

拾光的视觉设计参考了 **iOS 26 的 Liquid Glass 语言**。

通透的玻璃材质、壁纸透出的光影、轻轻流动的层次，再加上一点恰到好处的动态——我想让它不只是一个放链接的地方，也是一处你愿意停留片刻的小空间。

桌面上舒展开来，手机上也能慢慢逛；如果系统开启了“减少动态效果”，拾光也会跟着安静一些。活泼还是轻柔，都照顾到你，喵。

## 几个顺手的小用法

- **直接搜索**：输入名称或关键词，寻找需要的工具。
- **快速唤起**：按下 `⌘ / Ctrl + K` 聚焦搜索框，在搜索框中按 `Esc` 清空搜索。
- **按需浏览**：切换分类、排序，以及网格或列表视图。
- **先看再出发**：点击应用图标，了解用途、支持平台和收费类型，再前往官方网站。

不用一次认识所有工具。找到此刻真正需要的那一个，就已经很好啦。
